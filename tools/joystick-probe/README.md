# Joystick-Probe

Kleines Diagnose-Programm für den Thrustmaster TCA Sidestick. Es prüft, welche
Signale der Stick am PC liefert (Buttons, Hat, Achsen) und ob sie auch ankommen,
wenn ein anderes Fenster im Vordergrund ist.

1. Stick per USB anstecken.
2. `joystick-probe.exe` per Doppelklick starten (ein Konsolenfenster öffnet sich).
3. Den Anweisungen im Fenster folgen; jeder Schritt endet mit Enter.
4. Beim Hintergrund-Test (Schritt 6) in ein anderes Fenster klicken und Stick bewegen.
5. Am Ende die Datei `joystick-probe-log.txt` (liegt neben der exe) zurückschicken.
